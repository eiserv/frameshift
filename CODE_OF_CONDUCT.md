# Code of conduct

Treat participants with respect. Discuss technical decisions and evidence without personal attacks. Harassment, discrimination, threats, doxxing, and disclosure of private information are not accepted.

This applies to Frameshift issues, pull requests, reviews, and other project spaces. Maintainers may remove harmful content, close discussions, or restrict participation. They should explain moderation decisions where that can be done without exposing private information.

Report conduct concerns privately to the repository owner through an available private contact channel on their GitHub profile. Do not post sensitive reports or identifying information in public issues. Security vulnerabilities use the separate reporting process in [SECURITY.md](SECURITY.md).
