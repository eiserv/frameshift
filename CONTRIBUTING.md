# Contributing

Frameshift is under active development. The CLI currently provides help and version output; migration commands are not implemented. See [README.md](README.md) and [docs/ROADMAP.md](docs/ROADMAP.md).

External code contributions are not being accepted yet. Maintainers must choose and document contribution terms before accepting external patches. Public visibility alone does not change that policy.

Once the repository is public, bug reports and documentation questions may be filed as GitHub issues. Check existing issues first, describe expected and actual behavior, and include the Frameshift version and a minimal fictional reproduction. Never include real project source, credentials, private paths, or evaluation corpora. Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Maintainer changes follow [AGENTS.md](AGENTS.md): English artifacts, Conventional Commits, focused pull requests, synchronized documentation, and the relevant tests. The required CI check must pass before merge. Respect the [code of conduct](CODE_OF_CONDUCT.md).
