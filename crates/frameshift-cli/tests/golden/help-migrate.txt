Usage: frameshift migrate [<source>] [--to astro-preact] --out <dir> [--package <dir>]
       [--config <file>|--no-config] [--plan <plan.json>] [--dry-run] [--clean-staging]
Migrate the Next.js App Router project at <source>, by default the current directory, into a
new Astro project with Preact at <dir> (migrate v0, D-101). Static pages, layouts,
and components that the analysis rates auto or review are converted; everything else is
copied unchanged below .frameshift/unmigrated/ and listed in .frameshift/SUMMARY.md.
<dir> must not exist, and must not be inside <source> or contain it. Files are written to a
staging directory next to <dir> and renamed into place when complete. The source is never
modified, and no project code or external tool runs. --plan refuses to continue unless the
recomputed plan document equals the given one byte for byte; the given file is compared, never
executed. --dry-run lists the planned files and writes nothing. --clean-staging first removes
the marked staging directory of an interrupted run next to <dir>. frameshift.jsonc in <source>
or the --config file can set the target and the package; flags override it. Exit status: 0 on
success, 2 for invalid arguments, 3 when the source or configuration cannot be read or the plan
document differs, 4 when the output location is refused or cannot be written.
