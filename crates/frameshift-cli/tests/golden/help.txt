Frameshift: deterministic framework migration engine

Usage: frameshift <command> [options]

Commands available in this build:
  help [command]      Print usage for help, inspect, or version
  inspect [<source>]  Identify a project without changing it
  version             Print engine and build information

Options:
  -h, --help          Print usage
  --version           Print the short version string
  --format text|json  Select inspect or version output (default: text)
  --package <dir>     Inspect one package of a workspace

Analysis, migration, and verification are not implemented.
